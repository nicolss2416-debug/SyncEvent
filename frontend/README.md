# Frontend

Este directorio está reservado para la aplicación cliente de SyncEvent.

## Estado

Pendiente de implementación. La propuesta tecnológica es:

- React + Vite + TypeScript.
- Consumo de la API GraphQL del backend.
- Autenticación con Spring Security (JWT o sesión, por definir).

Cuando se inicialice el proyecto, este directorio contendrá su propio `package.json`,
scripts de desarrollo y documentación específica.
